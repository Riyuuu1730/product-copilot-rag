This folder contains the presentation for my Product Management Copilot project, an AI learning and prototyping project focused on understanding how retrieval augmented generation (RAG) works in practice.

The slides explain the problem, product concept, RAG workflow, key configuration decisions, evaluation approach, initial findings, and lessons learned.

## What the project explores

- How documents are processed and divided into chunks.
- How embeddings and semantic retrieval help find relevant information.
- How a local LLM generates answers using retrieved context.
- How retrieval settings affect the context provided to the model.
- How to evaluate answer grounding, citation quality, and refusal behaviour.

## My approach

I used Cursor AI to assist with implementation while focusing on understanding the underlying workflow, exploring product decisions, testing the prototype, and evaluating its limitations.

This project helped me develop a deeper understanding of the technical considerations behind document based AI assistants and the product decisions involved in assessing their reliability.
